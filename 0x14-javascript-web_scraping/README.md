# JavaScript Web Scraping

This project practices reading and writing files and making HTTP requests with Node.js.

## Tasks

- `0-readme.js`: Read and print a UTF-8 file.
- `1-writeme.js`: Write text to a UTF-8 file.
- `2-statuscode.js`: Print an HTTP GET status code.
- `3-starwars_title.js`: Print a Star Wars movie title.
- `4-starwars_count.js`: Count films featuring Wedge Antilles.
- `5-request_store.js`: Save a webpage response to a file.
- `6-completed_tasks.js`: Count completed tasks by user.

The scripts use the `request` package as required by the assignment.
