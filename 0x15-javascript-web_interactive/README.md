# JavaScript Web Interactivity

These exercises use plain JavaScript to change a webpage without reloading it.

## Tasks

- `0-script.js` changes the header text color to red.
- `1-script.js` changes every paragraph text color to blue.
- `2-script.js` changes the header text color to red when `#red_header` is clicked.
- `3-script.js` adds the `red` class to the header when `#red_header` is clicked.
- `4-script.js` switches the header between the `red` and `green` classes.
- `5-script.js` adds a new `Item` to `ul.my_list` when `#add_item` is clicked.
- `6-script.js` changes the header text when `#update_header` is clicked.

Open each provided `*-main.html` file in a modern browser to try its matching script.
